# TiM

[Русский](README.md) · [English](README.en.md) · [简体中文](README.zh-CN.md)

Кроссплатформенное десктопное приложение для личных проектов и задач. Основа — Electron: один код работает на Windows, macOS и Linux.

## Уже работает

- создание и удаление проектов;
- создание типов проектов и переключение между ними;
- автоматический перенос старых проектов в тип «Работа»;
- задачи внутри каждого проекта;
- классический Pomodoro: 25 минут фокуса, 5 минут отдыха и длинный 15-минутный перерыв после четырёх сессий;
- автоматический запуск перерыва и разные звуковые сигналы завершения работы и отдыха;
- прогресс текущего Pomodoro на значке приложения в панели задач Windows и Dock macOS;
- отдельная страница статистики с фокусом за текущий рабочий день, графиком за 7 дней и историей запусков;
- календарь с разовыми и ежегодными событиями, при необходимости с указанием времени;
- окно «План на сегодня» при запуске приложения и после смены даты, если на день есть события;
- сохранение текущего этапа и таймера между запусками;
- состояния задач «К выполнению», «В работе» и «Выполнена» в меню по правому щелчку на задаче; текущее состояние отмечено галочкой;
- журнал с датой и временем создания, начала и остановки работы, завершения, повторного открытия и удаления задач;
- одна текущая задача «В работе», отмеченная в списке задач; при начале работы над другой задачей работа над предыдущей останавливается;
- поиск в журнале по задачам, проектам и разделам, совместные фильтры по датам, разделу, проекту и задаче, включая удалённые; выбранный раздел ограничивает список проектов и задач, проект — список задач; история остаётся после удаления разделов, проектов и задач;
- необязательные комментарии с форматированием прямо в редакторе: жирный текст, курсив и списки с кружками или квадратами;
- редактирование названия задачи;
- переименование разделов, проектов и задач двойным щелчком;
- удаление разделов, проектов и задач через правый щелчок → «Удалить» (или Shift+F10), с подтверждением; удаление раздела удаляет вложенные проекты и задачи, но сохраняет историю журнала;
- кнопка «Обновить» появляется только при доступном обновлении и остаётся видна во время установки или для повторной попытки;
- автоматическое локальное сохранение в JSON;
- подтверждение перед удалением.

Язык можно изменить в приложении: **Настройки → Язык интерфейса → Применить** (русский, английский, китайский). Верхнее меню окна тоже переводится. Перед перезагрузкой интерфейса изменения сохраняются; текущий Pomodoro продолжает отсчёт. Пользовательские названия и комментарии не переводятся. Настройка сохраняется между запусками и обновлениями.

## Запуск

Требуется Node.js 22 или новее.

```powershell
npm install
npm start
```

## Установщик и обновления Windows

Готовый установщик скачивается со страницы [Releases](https://github.com/inzhevatkin/project-tasks/releases/latest). Для локальной сборки: `npm ci`, затем `npm run dist:win`; файл появится в `dist/TiM-setup-<версия>.exe`.

Перед установкой можно выбрать русский, английский или упрощённый китайский язык. Выбранный язык сохраняется и используется как в мастере установки, так и в интерфейсе программы. При автоматических обновлениях он не сбрасывается. Пользовательские названия проектов, задач и событий не переводятся.

Установленная версия проверяет GitHub Releases при запуске и затем каждые шесть часов. Одно нажатие «Обновить» скачивает новую версию, сохраняет последние изменения, устанавливает обновление без дополнительных окон мастера и перезапускает приложение. Во время загрузки можно продолжать работать; повторное нажатие не требуется. При ошибке можно повторить попытку той же кнопкой. При запуске через `npm start` обновление недоступно. Данные проектов и статистика при обновлении остаются в `%APPDATA%\project-tasks`.

Каждый коммит в `main` запускает GitHub Actions: тесты, сборку установщика и публикацию релиза вместе с `latest.yml`. Номер релиза вычисляется по количеству коммитов после версии `0.1.0`: первый новый коммит — `0.1.1`, следующий — `0.1.2`. Для локальных коммитов после `npm install` или `npm ci` хук автоматически обновляет версию в `package.json` и `package-lock.json`. Для коммитов, сделанных через GitHub, манифесты могут отставать, но версия опубликованного установщика всё равно вычисляется из истории Git.

Установщик пока не подписан доверенным сертификатом, поэтому Windows может показать предупреждение SmartScreen.

## Структура

- `electron/main.js` — создание окна и обработчики IPC;
- `electron/workspace-store.js` — загрузка JSON и очередь сохранения;
- `electron/preload.cjs` — безопасный мост между интерфейсом и файловой системой;
- `assets/icon.png` и `assets/icon.ico` — иконки приложения для Electron и Windows;
- `src/models.js` — модели проектов и задач;
- `src/renderer.js` — запуск приложения и переключение страниц;
- `src/workspace-controller.js` — проекты, задачи и автосохранение;
- `src/calendar.js`, `src/calendar-controller.js` — правила событий и страница календаря;
- `src/task-journal.js`, `src/journal-controller.js` — состояния задач и журнал;
- `src/pomodoro-controller.js` — жизненный цикл таймера и история сессий;
- `src/pomodoro.js`, `src/statistics.js` — правила циклов и расчёты статистики;
- `src/ui/` — элементы интерфейса, тема, колокольчик и отображение статистики;
- `src/index.html`, `src/styles.css` — интерфейс;
- `test/` — тесты модели.

Проекты, задачи, события и журнал хранятся в прежней папке `%APPDATA%\project-tasks` в файле `projects.json`. История Pomodoro и отметка о показе дневного плана хранятся в локальном хранилище Electron той же папки. Перед закрытием приложение сохраняет последние изменения. Окно дневного плана появляется, когда приложение запущено; закрытое приложение не присылает напоминаний.

Чтобы вести историю работы, нажмите правой кнопкой мыши на задачу и выберите «В работе». Выбор «К выполнению» останавливает работу, а «Выполнена» фиксирует её завершение. Выбор задачи в списке сам по себе не меняет состояние. Состояние «В работе» сохраняется между запусками до ручной остановки или завершения; это отметка текущей задачи, а не учёт отработанных часов. Записи журнала содержат названия на момент события. Для старых задач восстанавливаются известные даты создания; даты прошлых завершений не сохранялись и не добавляются задним числом.

## Логичные следующие шаги

1. Добавить сроки, приоритеты и теги.
2. Сделать поиск, фильтры и сортировку.
3. Добавить архив проектов.
4. Перейти с JSON на SQLite при росте данных.
5. Добавить подписанные установщики macOS и Linux-пакеты.
